# План работ — канонический документ лежит в репозитории CMS

Портал КЧС состоит из двух кодовых баз, и план у них общий. Чтобы он не расходился в двух местах, единственная актуальная версия хранится здесь:

- **`khf-site-cms/PROJECT_PLAN.md`** — сквозной план: карта системы, реестр проблем (P0…P3), разворот окружения, дорожная карта A → F, Definition of Done, известные подводные камни.
- **`khf-site-cms/AGENT_PROMPT.md`** — готовый промпт для запуска ИИ-агента.

Оба репозитория обычно лежат рядом:

```
khf-site/
├── khf-site-cms/     ← PROJECT_PLAN.md, AGENT_PROMPT.md, CMS_AUDIT.md, DEPLOYMENT.md
└── khf-site-front/   ← этот файл
```

## Помнить при работе с фронтом

- **Next.js 16 ≠ то, что помнит модель.** См. `AGENTS.md` в корне: перед правкой роутинга, кэширования, метаданных и `not-found` читать `node_modules/next/dist/docs/`. Middleware здесь называется `proxy` (файл `proxy.ts` в корне), `revalidateTag` требует 2-аргументную форму.
- **Локали:** в URL таджикский — `tj`, в API и `<html lang>` — `tg`. Маппинг только в `lib/i18n/config.ts`. При отладке API запрашивать `?locale=tg`: `?locale=tj` молча откатывается на русский.
- Правки метаданных и маршрутов проверять именно `npm run build` — часть ошибок Next в dev-режиме не проявляется.
