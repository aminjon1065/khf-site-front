# Подготовка контента к запуску

Список того, что нужно сделать **в CMS** до публикации портала. Фронтенд эти
записи не скрывает и не подменяет: фильтровать выдачу по словам в заголовках
(«тест», «demo») означало бы прятать реальное состояние базы, а рано или поздно
скрыть и настоящую публикацию с неудачным словом в названии.

Данные ниже — срез API локальной CMS на **16 сентября 2026 года**
(`https://khf-site-cms.test:8443/api/v1`, локаль указана в каждом пункте).
Перед запуском срез нужно снять заново: команды приведены рядом с каждым
пунктом.

---

## 1. Тестовые и демонстрационные материалы в новостях

Всего новостей: **153** (ru).

| Что | Slug | Почему мешает запуску |
|---|---|---|
| Тестовая запись | `novosti-testovaya` | Заголовок «Новости тестовая» попадает в слайдер главной, в RSS-подобные списки и в поисковую выдачу |
| Заполнитель на латинице | `laborum-earum-officia-laudantium-culpa-hic-cum-sit-52580` | Текст-рыба (lorem ipsum) в ленте официального портала |

Проверка:

```bash
curl -s 'https://<cms>/api/v1/news?locale=ru&per_page=100' \
  | jq -r '.data[] | select(.title | test("тест|test"; "i")) | .slug'
```

**Действие:** снять с публикации или удалить в CMS.

## 2. Slug'и длиннее контракта (ломают production-сборку)

Найдено **2** материала со slug'ом длиннее 180 символов (247 и 249 символов).

Почему это не косметика:

- имя файла прегенерации `.next/server/app/ru/news/<slug>.segments` выходит за
  **255 байт на компонент пути** — предел и NTFS, и ext4. Сборка падала
  с `ENOENT: mkdir` и роняла всю выкладку, а не одну страницу;
- тег кэша `cms:news:<slug>:ru` выходит за лимит Next.js в 256 символов —
  адресная ревалидация по вебхуку для такого материала не работала молча;
- входящий вебхук с таким slug'ом и так отвергается проверкой (`slug ≤ 180`
  в `parseRevalidationPayload`).

Фронтенд теперь защищён (`MAX_CMS_SLUG_LENGTH` в `lib/cache-tags.ts`): такой
материал остаётся полностью рабочим адресом, но не пре-рендерится на сборке и
обновляется по таймеру ISR, а не по вебхуку.

Проверка:

```bash
curl -s 'https://<cms>/api/v1/slugs/news?locale=ru' \
  | jq -r '.data[] | select(length > 180)'
```

**Действие (CMS):** ограничить длину slug при генерации из заголовка —
см. `docs/CMS_CONTRACT_REQUESTS.md`, запрос **C-1**.

## 3. Демонстрационные PDF в каталоге документов

Всего документов: **31**. У **15 из них** файл весит **192 байта** — это
файл-заглушка, а не документ: скачавший получит нечитаемый PDF.

| Размер | Записей |
|---|---|
| `PDF · 192 Б` (заглушки) | 15 |
| реальные файлы (24,8 КБ – 1,6 МБ) | 16 |

Проверка:

```bash
curl -s 'https://<cms>/api/v1/documents?locale=ru&per_page=100' \
  | jq -r '.data[] | select(.size | test("192 Б")) | .title'
```

**Действие:** заменить файлы настоящими либо снять записи с публикации.
Фронтенд показывает размер как есть — подменять его нечем и незачем.

## 4. Переводы: английская версия почти пуста

Портал объявляет три локали, но опубликованных переводов сильно меньше:

| Раздел | ru | tj (`tg`) | en |
|---|---|---|---|
| Новости | 153 | 152 | **3** |
| Инструкции | 11 | 11 | 6 |
| Объявления | 36 | 38 | **0** |
| Проекты | 6 | 6 | **0** |

Проверка:

```bash
for t in news instructions announcements projects; do
  for l in ru tg en; do
    printf '%s/%s: ' "$t" "$l"
    curl -s "https://<cms>/api/v1/slugs/$t?locale=$l" | jq '.data | length'
  done
done
```

**Что уже сделал фронтенд** (не выдаёт русский fallback за перевод):

- `hreflang` и `x-default` объявляют только локали с реально опубликованным
  переводом (источник — `/slugs/{type}?locale=`), а не все три механически;
- страница без перевода получает `robots: noindex, follow` и показывает честную
  заметку со ссылкой на доступную версию (`TranslationNotice`);
- локализованный `sitemap.xml` содержит только существующие языковые ветки, и
  ссылки взаимны.

**Действие (редакция):** либо опубликовать переводы, либо принять, что
английская ветка остаётся малой, — оба варианта теперь честны для робота и
для посетителя. Отдельно стоит решить, показывать ли `/en` в переключателе
языков на разделах, где переводов нет вовсе (объявления, проекты).

## 5. Материалы без изображения

Из 50 проверенных новостей у **4** нет `image_data`. Это не ошибка: слайдер и
карточки корректно переключаются в «редакционный» вид без пустой плиты-заглушки.
Отмечено, чтобы редакция знала: первый слайд главной без фото выглядит иначе.

---

## 6. Публичный адрес сайта

`NEXT_PUBLIC_SITE_URL` обязателен для production-сборки: из него собираются
`canonical`, `og:url`, JSON-LD и `sitemap.xml`. Сборка без него теперь падает с
понятным сообщением (`assertSiteUrlForBuild` в `lib/cms-readiness.mjs`), а не
публикует `http://localhost:3000` в метаданных.

Для локальной проверки production-артефакта: `SITE_URL_ALLOW_LOCAL=1 npm run build`.

---

## Что НЕ является задачей контента

Длинный заголовок новости (241 символ) делает первый слайд главной высоким.
Слайдер больше не «прыгает» при смене кадра — высота забронирована по самому
высокому слайду, — но сам кадр остаётся высоким. Это следствие заголовка, а не
вёрстки: обрезать официальный заголовок фронтенд не вправе.
